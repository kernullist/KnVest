## Why It's Complex

Implementing a working x64 VM interpreter inline requires:

### 1. API Resolution
```asm
; Need to resolve at runtime:
- GetStdHandle from kernel32.dll
- WriteFile from kernel32.dll
- Or: Use direct syscalls (NtWriteFile)
```

### 2. Register Management
```asm
; Store 16 VM registers:
- Use stack space: [rsp+0x00] = r0, [rsp+0x08] = r1, etc.
- Or: Use physical registers when possible
- Save/restore all caller-saved registers
```

### 3. NativeCall Implementation
```asm
; For ID 1 (print):
1. Get r0 (string offset in bytecode)
2. Get r1 (string length)
3. Calculate absolute address: bytecode_base + r0
4. Call GetStdHandle(-11) → stdout handle
5. Call WriteFile(stdout, string, length, &written, NULL)
6. Store result in r0
```

### 4. Calling Convention
```asm
; Windows x64 fastcall:
- Parameters: RCX, RDX, R8, R9, then stack
- Shadow space: 32 bytes before call
- Preserve: RBX, RBP, RDI, RSI, R12-R15
- Volatile: RAX, RCX, RDX, R8-R11
```

## Implementation Approaches

### Option A: GetProcAddress (Recommended)
```asm
1. Get kernel32.dll base from PEB
2. Parse export table
3. Find GetStdHandle and WriteFile addresses
4. Store in global variables
5. Use in NativeCall handler
```

### Option B: Direct Syscalls
```asm
1. Use NtWriteFile syscall directly
2. Syscall number: varies by Windows version
3. Requires hardcoding or dynamic lookup
4. More fragile across Windows versions
```

### Option C: Import Table Hook
```
1. Add imports to PE import table
2. Resolve at load time
3. Reference from VM interpreter
4. Cleanest but requires more PE modification
```

## Minimal Working Example

For hello-world specifically, the interpreter needs:

```asm
; Entry point
sub rsp, 0x80              ; Stack frame + space for 16 registers

; Load bytecode pointer
lea rsi, [rip + 0x100]     ; Offset to bytecode after stub

; Main loop
.loop:
    movzx eax, byte [rsi]  ; Fetch opcode
    inc rsi

    cmp al, 0xFF           ; Exit?
    je .exit

    cmp al, 0x01           ; LoadImm?
    je .load_imm

    cmp al, 0x0D           ; NativeCall?
    je .native_call

    jmp .loop

.load_imm:
    movzx ecx, byte [rsi]  ; Register number
    inc rsi
    mov rax, [rsi]         ; Value
    add rsi, 8
    mov [rsp + rcx*8], rax ; Store in register
    jmp .loop

.native_call:
    mov rax, [rsi]         ; Function ID
    add rsi, 8
    cmp rax, 1
    jne .loop
    call print_hello       ; Implemented below
    jmp .loop

.exit:
    mov rax, [rsp]         ; Return r0
    add rsp, 0x80
    ret

print_hello:
    ; Get r0 (string offset), r1 (length) from stack
    ; Call GetStdHandle(-11)
    ; Call WriteFile(stdout, bytecode_base + r0, r1, &written, NULL)
    ; Return
    ret
```
